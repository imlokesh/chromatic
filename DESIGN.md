# Chromatic interface
Operate mode. A compact Windows utility with a warm neutral canvas, ink typography, and restrained violet selection accents. Segoe UI follows native Windows utility conventions. A narrow left rail contains navigation; the main library uses aligned profile rows rather than dashboard cards. Search is the primary interaction. Browser initials, profile colors, names, and tags carry identity. Editing uses a focused side panel. Empty states describe actual next actions, not example profiles. Dark mode follows the operating system by default. All iconography uses Lucide; visible focus and reduced-motion behavior are required.
